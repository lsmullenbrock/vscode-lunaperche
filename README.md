# Lunaperche for VS Code

A dark VS Code theme ported from the [lunaperche Neovim colorscheme](https://github.com/fishmonger45/lunaperche-nvim).

## Development

1. Open this folder in VS Code.
2. Press `F5` (or `Ctrl+F5`) to launch an Extension Development Host.
3. Select **Lunaperche** from **Preferences: Color Theme**.

The theme is defined in [themes/lunaperche-color-theme.json](themes/lunaperche-color-theme.json).
